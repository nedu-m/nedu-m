Source for [nedum.xyz](https://nedum.xyz/), an evidence-led portfolio covering senior quality engineering, test automation, release ownership, product security research, and software delivery.

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

The site is a static Parcel build deployed through Vercel. The custom domain is configured in `CNAME`, and the Vercel fallback hostname redirects to `nedum.xyz`.
